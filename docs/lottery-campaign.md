# 宝石の即時抽選ゲーム

現在の参加方法は「URLを送る → ブラウザーで開く → 宝石を選ぶ → 即時結果表示」です。LINE Developers・LIFFの登録は不要です。実際に配るページはGoogle Apps ScriptのURL版で、[URL抽選の設定](lottery-url-setup.md) に手順を記載しています。共通URL版は同じブラウザーで1回を制限しますが、1人1回の本人確認ではありません。

`/lottery-demo/` に、ボルドー・ゴールドを基調にしたゲーム体験版を用意しています。宝石を選択し、抽選ボタンを押すと、1〜4等または落選の演出が表示されます。「体験版の演出を選ぶ」で画面を確認できます。`/lottery/` は本番入口で、接続確認までは準備中です。

## 現時点の範囲

賞品を1等「施術90分無料」、2等「衣装チェンジ無料」、3等「写真指名無料」、4等「パウダートリートメント無料」に変更しました。体験版では各等と落選を選んで表示できます。体験版のランダム結果は本番確率ではありません。

本番条件は `data/lottery-campaign.json` に保存しています。1等は0.1％（1,000分の1）、最大3名。2〜4等は各33.3％、人数上限なし、ハズレなしです。1等3名到達後は2〜4等を各3分の1で抽選します。必ず3名が1等に当たるものではありません。開催期限は2026年11月30日23:59まで（日本時間）です。サーバーは翌12月1日00:00を排他的な終了日時とします。特典の有効期限は無期限です。開始日は10月6日00:00と仮置きしており、実際の受付は接続・公開完了後に始まります。期限延長に伴うキャンペーンIDの変更は行わず、既存の参加制限・抽選結果を維持します。

`node scripts/build-lottery-line.mjs` でスマホHTMLの条件欄を更新し、続けて `node scripts/build-lottery-url.mjs` でURL参加用HTMLとGoogle側のコピー用一式を生成します。URL用の実デプロイと結合試験はまだ完了していません。対象コースや予約時の利用条件、特典の1回使用管理は別途必要です。

- 静的出力で動く体験版です。実際の応募、LINE認証、当選権、クーポン、当選枠の消費は一切発生しません。
- ランダム結果はブラウザー内のデモです。設定した本番確率ではなく、正式開催には流用しません。
- 「公式LINEを見る」は既存の公式アカウントへのリンクです。友だち追加やLINE本人確認の証明にはなりません。
- 体験版にはnoindexを設定し、トップページ・sitemapには導線を追加していません。noindexはアクセス制限ではありません。
- モーション軽減設定に対応。結果へフォーカスを移し、連打による重複演出を防ぎます。

## 正式開催までに必要な作業

1. 期間・確率・特典有効期限は上記の条件を使用する。無料の対象コース、指名料等の範囲、対象者、予約時の利用条件は主催者が決める。締切時に1等が3名未満でも追加抽選は行わない。
2. 参加制限の方法を決める。共通URL版はブラウザー識別子を保存する手軽な方法で、保存削除・別端末等の再参加は防げない。より強い制限を求める場合は個別参加URLやSMS認証へ変更する。
3. URL版ではサーバーにキャンペーン・ブラウザー識別子のハッシュ・結果・当選枠を保存し、同じ識別子への再試行では既存結果を返す実装を用意した。実際のApps Scriptへデプロイする。
4. 台帳の読み取り・判定・書き込み・flushはScriptLock内で行い、全参加者を通じて1等3名の上限を管理する。ブラウザーの保存だけで全体の当選人数を数えない。実サービスでの動作を確認する。
5. URL版の画面は `google.script.run` によるサーバー結果のみ表示し、通信失敗時は抽選を止めて保存済み結果を再確認する。デモページのローカル乱数で代用しない。Reactの `LotteryGame.jsx` は引き続き体験版である。
6. 当選者へ一意の引換コードを発行し、スタッフ側で1回のみ使用できるようにする。公開画面に氏名等を出さない。スタッフ用の当選・使用履歴を用意する。
7. URL版からデモUI・演出選択・デモ乱数は除去済み。実接続の確認後に発行された `/exec` URLを配布する。LINE配信等で送る場合も、実際の配信は別の操作になる。

## 検証方法

Node 20 / npm 10 を使用し、リポジトリのルートで `npm run validate-data` と `npm run build` を実行します。開発サーバーとビルドは `.next` を共有するため同時実行しません。

ブラウザーで320px/390px/1440px、宝石未選択、選択、連打、当選/落選、再体験、キーボード、モーション軽減、リロードを確認します。LINEリンクの確認は送信や追加を実行せず、リンク先のみ確認します。
