# 公式LINEから抽選を始める設定手順

**旧方式の手順です。現在は [URL抽選の公開手順](lottery-url-setup.md) を使用します。** LINE Developers・LIFFの登録作業は進める必要がありません。

抽選ページ・サーバーのコードは用意済みです。以下は管理者自身のLINE・Googleアカウントで行う設定です。現時点ではLIFF ID、サーバーURLが空で、サイトの公開と実LINEでの接続試験も未完了です。

## 1. LINEログインチャネルを用意する

1. [LINE Developers](https://developers.line.biz/console/)へログインします。
2. 公式LINEのMessaging APIチャネルが所属するプロバイダーを開きます。既存のLINEログインチャネルがあれば使用できます。なければ同じプロバイダーで「LINEログイン」チャネルを作成し、アプリタイプに「ウェブアプリ」を選びます。
3. チャネル基本設定で対象の公式LINEを「リンクされたLINE公式アカウント」に設定します。今回のサイトに登録されている公式LINEは `@284lfsqm` です。
4. 「チャネルID」を控えます。Messaging APIのチャネルIDと取り違えないでください。チャネルシークレットは共有不要です。

## 2. LIFFアプリを追加する

LINEログインチャネルの「LIFF」タブからアプリを追加します。

| 項目 | 入力する内容 |
| --- | --- |
| LIFFアプリ名 | AROMA DIAMOND 抽選 |
| サイズ | Full |
| エンドポイントURL | `https://aroma-daiamond.com/lottery-line.html` |
| Scope | `openid` と `profile` |
| ボットリンク機能 | 友だち追加を案内する設定を有効にする（表示される場合） |

このエンドポイントは公開予定のURLです。現在公開済みという意味ではありません。保存後の「LIFF ID」を控えます。利用者へ案内する参加リンクは `https://liff.line.me/LIFF_ID` です。実際のIDに置き換えるまでは配布しません。

開発中は管理者・テスターで接続を確認します。一般公開前にはLINEログインチャネルの公開状態を確認します。

## 3. Google側に抽選専用の台帳を作る

1. [Googleスプレッドシート](https://sheets.google.com/)で新規作成し、名前を「AROMA DIAMOND 抽選台帳」にします。共有は非公開のままにします。
2. この新しいシートの「拡張機能 → Apps Script」を開きます。
3. 初期の `myFunction` を削除し、`apps-script/lottery-install.gs` の内容を全て貼って保存します。このファイルにはサーバーと初期設定がまとまっています。既存のLINE予約用Webhookプロジェクトには貼りません。
4. スプレッドシートのタブを開いた状態で、Apps Scriptの実行対象を `setupLottery` にして実行します。初回は自分が作成したスクリプトへの権限を確認して許可します。
5. スプレッドシートに表示される入力画面に、手順1のLINEログインチャネルIDを入力します。キャンセルした場合は保存しません。
6. 専用の「抽選参加台帳」と設定が作られます。既存の抽選結果を削除せず、違うキャンペーンID・チャネルID・シートIDでの上書きは停止します。

自動入力される条件は、1等0.01％・最大3名、2〜4等各33.33％・人数上限なし、1等枠終了後は下位各3分の1、開催期限2026年11月30日23:59まで（日本時間）です。特典の有効期限は無期限です。特典を1回だけ使用する管理は別途必要です。

## 4. Apps Scriptのウェブアプリをデプロイする

1. 「デプロイ → 新しいデプロイ」で種類を「ウェブアプリ」にします。
2. 実行ユーザーを「自分」、アクセスできるユーザーを匿名アクセスも許可する「全員」にします。組織の設定等でこの選択ができない場合、その状態では一般参加者向けに接続できません。
3. デプロイ後のウェブアプリURLを控えます。末尾が `/exec` のURLを使い、開発用 `/dev` URLは使用しません。

URLが公開されても、抽選にはサーバー側で検証したLINE本人確認が必須です。スプレッドシート自体を公開する必要はありません。

## 5. 接続情報を反映して確認する

ここまでで取得した「LIFF ID」「LINEログインチャネルID」「Apps Scriptの `/exec` URL」をCodexへ伝えてください。いずれも接続用の識別子です。チャネルシークレットやアクセストークンは送らないでください。

Codexが `public/lottery-line-config.json` のLIFF ID・接続先を設定します。サイト公開が必要なので、コード反映と公開も完了させてから確認します。Google側のプロパティには手順3でLINEログインチャネルIDが入ります。

実LINEで認証・友だち追加・抽選結果の保存を試し、同じアカウントから再び開いても再抽選できないことを確認します。試験には本番と別のキャンペーン・台帳を使います。本番の3名枠を試験で消費しません。CORSや認証で失敗する場合は抽選を停止したまま原因を修正します。

接続確認後に公式LINEのリッチメニューや配信へLIFF参加リンクを設定します。実際の配信は別の公開操作です。
