## エステラブの出勤（2026-11-26 にツールへ追加）
- 週別の出勤表 /admin/shop/therapist_schedule/weekly を、`?day=` で営業日の今日から7日分にそろえて読む。
- 入れ方：セルを押す → 小窓で出勤・退勤（6:00〜翌6:00、30分刻み。値は "1230"・"2930" の形）→「決定する」→ 表の上の「保存する」でまとめて保存（「…の週の出勤情報を保存します」の確認だけ承認）。
- いまは「出勤を入れる」だけ。登録済みの出勤の変更・解除は止まって知らせる（解除は受付と結びつくことがあるため、必要になったら確かめてから追加する）。
- 試しに1件 → 読み直して一致 → 残り5件 → 変更点0件（一致）を確認。

直したこと：
- 作業用ブラウザ（browser.mjs）が、diff / apply がつないだページの確認画面を勝手に閉じていた（Playwright は受け手のいない確認画面を自動で閉じる）→ 何もしない受け手を付けて、判断をツールに任せる。このとき何も保存されていないことを diff で確認済み。
- 小窓の中身は後から読み込まれる → その人・その日の中身になるまで待ってから入力する。
- 出勤がある人の名前の欄には「LINEで送る」などのリンクが増える → 名前のリンクだけを読む。
